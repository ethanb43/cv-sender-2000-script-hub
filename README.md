## Overview

CV Sender 2000 targets the automation of CV and resume submission tasks. Everything runs on Google Apps Script, and the whole experience is dressed up in a look and feel borrowed from Windows 2000 -- so a practical job-application toolchain meets a distinctly nostalgic visual layer.

If you are looking for a Google Apps Script foundation to build CV-related automation on top of, this collection is meant as that starting point. Development attention goes to three areas: the submission workflow itself, how the scripts are organized, and the Windows 2000-inspired presentation that sets the project apart.
